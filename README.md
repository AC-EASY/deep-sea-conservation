# deep-sea-conservation
Deep Sea Conservation Coalition (DSCC) — A Public Welfare Awareness Website 

This website is dedicated to promoting the Deep Sea Conservation Coalition (DSCC), a global alliance of over 130 NGOs working to protect vulnerable deep-sea ecosystems. The website consists of three pages: the Home page introduces the organization's mission, history, and current priorities; the Key Threats page highlights the three major threats to the deep sea — deep-sea mining, destructive fishing, and geoengineering; the Solutions page presents the DSCC's strategies for protecting seamounts, opposing deep-sea mining, and strengthening international governance.

The visual design adopts a deep ocean-inspired color palette with dark blues and teals, creating an immersive underwater atmosphere. Large hero images of the deep sea will be used on each page to immediately engage visitors. The layout follows a modern, clean structure with a consistent header navigation and footer across all pages. On desktop, content is arranged in multi-column layouts using CSS Grid and Flexbox, while on mobile devices it collapses into a single-column format for readability. Typography uses a custom web font for headings to convey a professional and authoritative tone. Interactive elements include a smooth-scroll navigation, an image carousel on the home page, and expandable content sections on the threats page. The website is purely informational — no registration, donation, or action buttons — focusing entirely on raising awareness about the importance of deep-sea conservation.
